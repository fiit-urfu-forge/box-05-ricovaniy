---
name: Stop after each checklist item
description: User wants explicit pause after each completed checklist task before continuing to the next
type: feedback
---

После выполнения каждого пункта чеклиста — останавливаться и ждать команды на следующий пункт.

**Why:** Пользователь хочет ревьюить каждую часть перед тем как двигаться дальше. Это его способ контроля над большим многоэтапным проектом.

**How to apply:** В начале каждого пункта пометить TaskUpdate → in_progress, в конце TaskUpdate → completed, затем кратко отчитаться о результате (что сделано, что собирается, что осталось) и НЕ переходить к следующему пункту автоматически. Ждать явного сигнала продолжать.
